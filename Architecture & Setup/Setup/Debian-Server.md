This is a minially Debian Server environment, with no desktop environment or GUI. It is a straight  bash command line. It is running on a Dell Latitude 7490 with 16 gigs of ram and 109 gigs of root and a 6 gig swap. It is as minimal as I could of gotten it, with very few packages to note. Some of the packages or services that I did install would be a game server for a semi realistic workload and also things like docker in order to learn about containers, openssh servers for ssh, nginx for network configurations, apache2 for web servers, stress in order for resource monitoring/stress-testing, alongside the Wazuh-agent for server monitoring. This would be just the wazuh agent and none of the other Wazuh software.
