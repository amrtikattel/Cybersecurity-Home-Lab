This is a virtual machine configured in QEMU/KVM in Virt Manager. The OS its running would be Parrot-OS, its Hypervisor is KVM, with x86_64 architecture witha  Chipset of Q35 and its firmware is Bios. I have given it 4 virutal CPUs and also the configuration, would be to copy the host CPU configuration. I also had to setup the Cpu topology with 4 sockets and 1 core and 1 thread. As for the memory dedicated to the Virutal Machine it would be 5251 megabytes. As for the disk, I have dedicated 20 gigabytes for the virtual disk. I configured the Virtual Network Interface to use a Virtual Network default NAT and a device model using VirtIO. I have also setup a Spice Server in order to copy and paste things from the Arch Host to the Parrot Virtual machine. Aside from that all the settings where the default.
Aside from the configuration, the ParrotOS is a KDE Plasma install running on wayland. It is a bash command-line.
Some of the packages  I installed would be THC-Hydra,CUPPS,NMAP,Curl, Greenbone/OpenVas, Nuclei, Metasploit Framework,sqlmap, LinePEAS,pspy. These would be tools that will be used against or to do some research into the server itself.
